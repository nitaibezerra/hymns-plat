# Guia do Usuário

Bem-vindo ao **Portal de Hinários do Santo Daime**!

Este guia vai ajudar você a navegar pelo portal, buscar hinos, visualizar letras e contribuir com a comunidade.

## O que você pode fazer

### Sem conta (visitante)

- :material-magnify: **Buscar hinos** por título, letra ou hinário
- :material-book-open-variant: **Navegar hinários** completos
- :material-text: **Visualizar letras** de todos os hinos

### Com conta (usuário registrado)

- :material-upload: **Fazer upload** de novos hinários
- :material-heart: **Favoritar** hinos para acesso rápido
- :material-comment-text: **Comentar** em hinos
- :material-account-group: **Seguir** outros contribuidores
- :material-bell: **Receber notificações** de atividades
