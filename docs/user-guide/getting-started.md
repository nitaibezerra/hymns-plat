# Primeiros Passos

Este guia vai ajudar você a entender a interface do Portal de Hinários.

## Interface Principal

### Página Inicial

Ao acessar o portal, você verá:

1. **Barra de navegação** - Menu com links para as principais seções
2. **Barra de busca** - Encontre hinos rapidamente
3. **Estatísticas** - Total de hinários e hinos no portal
4. **Hinários em destaque** - Últimos hinários adicionados

### Menu de Navegação

O menu principal contém:

| Link | Descrição |
|------|-----------|
| **Home** | Página inicial com estatísticas |
| **Hinários** | Lista completa de hinários |
| **Buscar** | Página de busca avançada |
| **Entrar** | Login ou criar conta |

## Funcionalidades Básicas

### Buscar Hinos

A barra de busca está disponível em todas as páginas. Para buscar:

1. Digite o termo de busca (título, trecho da letra, nome do hinário)
2. Pressione ++enter++ ou clique no ícone de lupa
3. Veja os resultados ordenados por relevância

!!! tip "Dica"
    A busca é inteligente e encontra resultados mesmo com pequenos erros de digitação.

### Navegar por Hinários

Para explorar um hinário completo:

1. Clique em **Hinários** no menu
2. Encontre o hinário desejado na lista
3. Clique em **Ver Hinário** para ver todos os hinos
4. Clique em qualquer hino para ver a letra completa

### Visualizar Letras

A página do hino mostra:

- Título e número do hino
- Nome do hinário (link para voltar)
- Letra completa formatada
- Metadados (estilo, data, etc.)
- Botões sociais (se logado)

## Criar Conta

Para contribuir com o portal (upload, favoritos, comentários), você precisa criar uma conta:

1. Clique em **Entrar** no menu
2. Clique em **Criar conta**
3. Preencha seus dados ou use login social

Veja mais em [Contas de Usuário](user-accounts.md).
