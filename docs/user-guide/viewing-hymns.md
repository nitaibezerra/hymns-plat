# Visualizar Letra de Hinos

Aprenda sobre a página de detalhes de um hino.

## Página do Hino

Quando você clica em um hino, vê a letra completa formatada.

## Informações do Hino

### Cabeçalho

No topo da página você encontra:

- **Número** do hino no hinário
- **Título** em destaque
- **Breadcrumb** - Link para voltar ao hinário

### Letra Completa

A letra é exibida preservando a formatação original:

- :material-check: Quebras de linha originais
- :material-check: Estrofes separadas
- :material-check: Espaçamento correto

### Metadados

Quando disponíveis, você verá:

| Campo | Descrição |
|-------|-----------|
| **Estilo** | Valsa, Marcha, Mazurca, etc. |
| **Recebido em** | Data em que o hino foi recebido |
| **Oferecido para** | Pessoa dedicatária |
| **Repetições** | Ex: "1-4, 5-8" |
| **Instruções extras** | Instruções especiais de canto |

## Botões Sociais

Se você estiver logado, verá botões para:

- :material-heart: **Favoritar** - Adiciona aos seus favoritos
- :material-comment-text: **Comentar** - Deixar um comentário

Veja mais em [Recursos Sociais](social-features.md).

## Navegação

### Voltar ao Hinário

Clique no nome do hinário no breadcrumb para voltar à lista de hinos.

### Buscar Outro Hino

Use a barra de busca no topo para encontrar outro hino.

## Imprimir

Para imprimir a letra de um hino:

1. Use a função de impressão do navegador (++ctrl+p++ ou ++cmd+p++)
2. O portal otimiza a página para impressão

!!! tip "Dica"
    No modo de impressão, apenas a letra é impressa, sem menus ou botões.

## Compartilhar

Cada hino tem uma URL única que você pode compartilhar:

```
https://portal-hinarios.com.br/hino/uuid-do-hino/
```

Copie a URL da barra de endereço do navegador para compartilhar.
