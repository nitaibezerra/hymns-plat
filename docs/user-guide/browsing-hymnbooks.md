# Navegar por Hinários

Explore hinários completos navegando pela lista.

## Lista de Hinários

Acesse **Hinários** no menu para ver todos os hinários disponíveis.

### Informações Exibidas

Para cada hinário você vê:

- :material-image: **Capa** (quando disponível)
- :material-book: **Nome** do hinário
- :material-account: **Dono** (quem recebeu)
- :material-music-note: **Quantidade** de hinos
- :material-text: **Descrição** resumida

### Ordenação

Os hinários são ordenados alfabeticamente por nome.

### Paginação

A lista mostra 20 hinários por página. Use os botões de navegação:

- **Primeira** - Ir para primeira página
- **Anterior** - Página anterior
- **Próxima** - Próxima página
- **Última** - Última página

## Detalhes do Hinário

Clique em **Ver Hinário** para ver todos os hinos.

### Informações Completas

A página de detalhes mostra:

- :material-image: **Capa grande** (300x400)
- :material-book: **Nome completo** e nome curto
- :material-account: **Dono** do hinário
- :material-text: **Descrição** completa
- :material-counter: **Total de hinos**

### Tabela de Hinos

Todos os hinos são listados em uma tabela:

| Número | Título | Estilo |
|--------|--------|--------|
| 1 | Lua Branca | Valsa |
| 2 | Tuperci | Marcha |
| 3 | Ripi | Mazurca |

Clique em qualquer linha para ver a letra completa do hino.

## Navegação entre Hinos

Quando estiver na página de um hino, você pode:

- Clicar no nome do hinário para voltar à lista de hinos
- Usar os links de navegação (anterior/próximo)

## Hinários Populares

Na página inicial, você verá os hinários mais acessados e os adicionados recentemente.

!!! tip "Dica"
    Use a busca se você já sabe qual hino procura. Use a navegação para explorar hinários completos.
