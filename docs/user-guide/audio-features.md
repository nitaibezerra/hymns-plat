# Recursos de Áudio

O portal suporta áudios para os hinos.

!!! note "Em Desenvolvimento"
    O player de áudio completo está sendo desenvolvido. Esta página descreve as funcionalidades planejadas.

## Player de Áudio

Quando um hino tem áudio disponível, você verá um player na página.

### Controles

- :material-play: **Play/Pause** - Tocar ou pausar
- :material-skip-previous: **Anterior** - Hino anterior no hinário
- :material-skip-next: **Próximo** - Próximo hino
- :material-volume-high: **Volume** - Ajustar volume
- :material-repeat: **Repetir** - Repetir hino atual
- :material-download: **Download** - Baixar áudio (se permitido)

### Formatos Suportados

| Formato | Qualidade |
|---------|-----------|
| MP3 | Até 320kbps |
| OGG Vorbis | - |
| FLAC | Lossless |

## Contribuir com Áudio

Você pode enviar áudios para hinos existentes.

### Requisitos

- :material-check: Qualidade mínima: 128kbps
- :material-check: Formato: MP3, OGG ou FLAC
- :material-check: Tamanho máximo: 25 MB por arquivo
- :material-check: Ter direitos para compartilhar

### Como Enviar

1. Vá para a página do hino
2. Clique em **Adicionar Áudio**
3. Arraste o arquivo ou selecione
4. Adicione informações:
   - **Fonte** - Onde foi gravado
   - **Data** - Quando foi gravado
   - **Créditos** - Quem cantou/gravou
5. Clique em **Enviar**

### Moderação

Áudios passam por verificação:

- Validação de formato e qualidade
- Verificação de correspondência com o hino
- Aprovação por moderador

## Playlists

Crie playlists personalizadas:

1. Navegue pelos hinos
2. Clique no :material-plus: ao lado do player
3. Selecione playlist ou crie nova
4. Acesse suas playlists no perfil

### Gerenciar Playlists

No seu perfil você pode:

- Criar novas playlists
- Editar nome e descrição
- Reordenar hinos
- Deletar playlists

## Download

Alguns áudios permitem download:

- :material-download: **Download individual** - Um hino por vez
- :material-folder-download: **Download do hinário** - ZIP com todos os áudios

!!! info "Direitos Autorais"
    Respeite os direitos autorais. Downloads são apenas para uso pessoal.

## Problemas com Áudio?

Se o áudio não tocar:

1. Verifique volume do sistema e do player
2. Tente outro navegador
3. Verifique conexão de internet
4. Limpe cache do navegador

Veja [Solução de Problemas](troubleshooting.md) para mais detalhes.
