# Portal de Hinários do Santo Daime

Bem-vindo à documentação do **Portal de Hinários do Santo Daime**, uma plataforma para pesquisa, visualização e compartilhamento de hinários do Santo Daime.

## O que é o Portal?

O Portal de Hinários é uma aplicação web que permite:

- :material-magnify: **Buscar hinos** por título, letra ou hinário
- :material-book-open-variant: **Navegar hinários** completos com todos os hinos
- :material-text: **Visualizar letras** formatadas e completas
- :material-account: **Criar conta** e contribuir com conteúdo
- :material-music: **Ouvir áudios** de hinos (em desenvolvimento)
- :material-heart: **Favoritar** seus hinos preferidos
