ii · Três pilares
solução
Fase 2

Uma plataforma viva.
Três pilares que se sustentam.

i.

Ler
com fidelidade.

O hino exatamente como foi cantado. PDF-flow preservando a página original; modo carrossel para leitura em tela; mobile pensado para os trabalhos.

ii.

Revisar
com método.

Cada alteração registrada, comparável, reversível. Diff de revisor — não de programador. Atalhos de teclado para sessões longas. Conflitos avisados antes, não depois.

iii.

Contribuir
com cuidado.

OCR para resgatar PDFs antigos. Wizard de submissão guiado. Cada contribuição entra na mesma fila — tratada com o mesmo rigor de revisão.

vi · Editor · Publicar
publicar é assinar
Tela 6 / 6 · Publicar

Publicar é
deliberado.

Antes do hino virar a versão pública, o Editor pede uma nota de revisão — uma frase que diga ao próximo revisor o que mudou e por quê.

Essa nota vira parte do histórico permanente. Não é um botão escondido — é um gesto consciente.
